# Dom Pogrzebowy Jasek — визуальный редизайн (статический прототип)

Рабочий прототип нового сайта [jasek.pl](https://www.jasek.pl/): HTML/CSS/JS без фреймворков.
По просьбе заказчика WordPress-тема **пока не делается**: сначала утверждается визуал.
Разметка и CSS собраны так, чтобы их можно было потом перенести в шаблоны WordPress-темы.

## Запуск

```bash
npm run build   # генерирует site/**/index.html из src/
npm run serve   # http://127.0.0.1:8090/
```

## Хостинг превью

- **Vercel** — `vercel.json` (сборка `npm run build`, папка `site`).
- **GitHub Pages** — ветка `gh-pages`, собирается командой `npm run deploy:pages` (сборка с `BASE_PATH=/jasek-redesign`).
- Превью-сборки помечены `noindex` (meta, `X-Robots-Tag`, `robots.txt`), чтобы копия не конкурировала с настоящим jasek.pl в поиске. Для боевого сайта: `PRODUCTION=1 npm run build`.

## Структура

| Путь | Что это |
|---|---|
| `src/data.mjs` | Проверенные данные компании: филиалы, телефоны, часы, услуги |
| `src/layout.mjs` | Общие шаблоны: `<head>`/SEO, шапка, мобильное меню, футер, панель вызова, карточки |
| `src/pages/home.mjs` | Главная страница |
| `src/pages/inner.mjs` | Внутренние страницы: шаблоны «статья с боковой панелью», «услуга», «каталог услуг», «контакт» |
| `site/assets/css/main.css` | Дизайн-система (токены, компоненты); при сборке минифицируется в `main.min.css` |
| `site/assets/js/main.js` | Меню, мобильный диалог, валидация формы, анимации при прокрутке, счётчики, параллакс (без зависимостей) |
| `site/assets/img/` | Реальные фото компании с jasek.pl (WebP, 640/1400 px) + hero-изображение |
| `site/assets/fonts/` | Newsreader + Source Sans 3 (self-hosted, OFL, с польскими символами) |
| `public/assets/openart/` | Исходник hero-изображения (OpenArt, nano-banana-2) |

## Анимации

- Вход первого экрана: слова заголовка (разбиваются при сборке в `src/build.mjs`), шторка на фото, рамка.
- При прокрутке: поочерёдное появление блоков, шторки на фото, прорисовка галочек, счётчики цифр.
- Микро-взаимодействия: подчёркивания, заливка кнопок, «звонок» иконки телефона; плавные переходы между страницами (View Transitions), полоса прогресса чтения.
- Всё отключается при `prefers-reduced-motion: reduce`; без JS контент виден полностью. Нижняя панель вызова на мобильном не анимируется.

## Расхождения на живом сайте — нужно уточнить у заказчика

1. **Крематорий.** Главная: «posiada własne… krematorium». Страница `/kremacja/`: «współpracuje z pierwszym i największym krematorium». В прототипе использована осторожная формулировка «współpracujemy».
2. **E-mail филиала Zabrze** на сайте указан `gliwice@jasek.pl`. Оставлен как есть.
3. **Knurów.** `/transport-zmarlych/` упоминает филиал в Knurowie, но адреса нет нигде. В прототипе Knurów упомянут только в meta description страницы транспорта.
4. **Zasiłek pogrzebowy.** Фраза «kwota zasiłku w pełni wystarcza» убрана: сумма пособия меняется, а это утверждение мы проверить не можем. Формулировка о праве на пособие уточнена.
5. **Политика конфиденциальности** содержит плейсхолдер «[adres e-mail Administratora]» и мусорные ссылки-цитаты («Cyrek Digital+1…»). В прототипе текст очищен, вверху стоит пометка о необходимой юридической проверке.
6. **Логотип** доступен только как растровый PNG 298×162. Для чёткости нужен векторный (SVG) файл.
7. **Трекинг на живом сайте:** тег Google Ads `AW-17705887351` и Universal Analytics `UA-79664923-1` встроены в тему **без согласия** (UA к тому же отключён Google). Тег Ads стоит перенести в Complianz (категория «marketing»).

## Что не работает в прототипе (и почему)

- **Форма обратного звонка** проверяет поля на клиенте и честно сообщает, что ничего не отправлено. Отправка подключается в WordPress через Contact Form 7 (плагин уже установлен на jasek.pl).
- **Cookie-баннер (Complianz)** — плагин WordPress. Кнопка «Zarządzaj zgodą» в футере появляется только там, где Complianz активен.
- **DE/EN** ссылаются на живые `/de/` и `/en/`. Это отдельные сайты multisite, их перевод в новом дизайне — следующий этап.
